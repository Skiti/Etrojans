# RANSOM APP

## Usage
1. **Start the Ransom Server**: Ensure the ransom server is running on your computer.
2. **Configure IP Address**: Open `app/src/main/java/com/malicious/scootertoolkit/api/ApiClient.kt` and change the `IP` variable to match your computer's IP address and port (e.g., `192.168.1.103:8000`).
3. **Build and Install**: Open this project in Android Studio, build it, and install it on an Android device.
4. **Permissions**: Grant the requested permissions (e.g., Bluetooth, Location).

The app can scan for nearby Xiaomi e-scooters, flash a malicious firmware on them, perform our E-Trojans attacks, and restore an undervolted battery.
